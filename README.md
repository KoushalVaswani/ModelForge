# ⚡ModelForge

> A Machine Learning Model Selection & Hyperparameter Tuning Platform

ModelForge is an interactive Streamlit-based ML platform that allows users to upload a dataset, explore it, train multiple ML models, compare their performance, and find the best model with optimized hyperparameters.

## 🚀 Live Demo

👉 https://modelforge-kv96.streamlit.app/

## ✨ Features

- 📂 Upload CSV datasets
- 🔍 Dataset overview & analysis
- 🤖 Classification & Regression models
- 📊 Model performance comparison
- ⚙️ Hyperparameter tuning using RandomizedSearchCV
- 🏆 Best model recommendation
- 📈 Performance metrics
